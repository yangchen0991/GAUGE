## 4. 实时与额度接入边界（冻结）

三个独立能力分别验收，互相不得冒充：

1. 历史读取：本地 SQLite + rollout JSONL 只读。SQLite 用 mode=ro 短事务；rollout 按文件 mtime/大小增量。已验证可行（本清单即其产物）。
2. 日志增量观察：活跃 rollout 文件尾部增量读取 + SQLite 轮询；阶段 2 实现读取位置书签，处理文件替换与跨日新文件。
3. 官方实时接口：codex app-server（本机 0.147.0）JSON-RPC over stdio，方法契约以 learn.chatgpt.com/docs/app-server 为准（thread/*、account/rateLimits/read 与 updated、account/usage/read；该文档经研究核实为 OpenAI 官方）。GAUGE 自起独立 app-server 子进程；绝不附着或探测桌面端与其他进程的内部端口，绝不复制 auth.json 或读取其值。能否观察到其他端正在进行的实时回合，作为独立探针在阶段 2 验证，未验证通过不宣称实时。app-server 要求新的登录/凭据操作时，停下交用户决策。

额度展示规则：历史额度曲线来自 rollout rate_limits 快照（必须带时间戳）；实时额度仅在 app-server 探针验证通过后接入；读不到显示"暂不可用"，绝不显示 0%。
