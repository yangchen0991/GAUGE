# AI Agent 监控台 — Windows 桌面版

用系统窗口 + 托盘常驻的方式运行上级目录的《AI Agent 监控台》网页版，无需浏览器，
支持自动定时刷新与今日用量提示。

## 目录内容

| 文件 | 作用 |
|---|---|
| `app.py` | 主程序（双进程：托盘主进程 pystray + 窗口子进程 pywebview，Pipe 通信） |
| `启动监控台.pyw` | 无控制台入口，双击即用（内部以 runpy 运行 app.py） |
| `安装依赖.bat` | 一键安装 pywebview、pystray（含 Pillow） |
| `创建桌面快捷方式.bat` | 在桌面生成「AI Agent 监控台.lnk」（目标 pythonw.exe） |
| `README.md` | 本说明 |
| `app.log` | 运行日志（自动生成，追加写） |
| `monitor.ico` | 托盘/快捷方式图标（首次运行自动生成） |
| `smoke_result.json` | `--smoke` 冒烟自检结果（自动生成） |

上层目录的 `refresh.py`、`AI-Agent监控台.html` 为数据与页面来源，桌面版只读复用，不做修改。

## 环境要求

- Windows 10/11（64 位）
- Python 3.10+（本机验证：3.13.7，`python` 已加入 PATH）
- Microsoft Edge WebView2 Runtime（Win10/11 一般自带；缺失时程序会弹窗提示并可一键打开微软下载页）

## 首次使用

1. 双击 `安装依赖.bat`（等价于 `pip install pywebview pystray`）。
2. 双击 `启动监控台.pyw`（或 `python app.py`）。
   首次运行会自动生成 `monitor.ico`；若上层目录还没有 `AI-Agent监控台.html`，会先自动跑一次数据刷新生成页面。
3. 建议运行一次 `创建桌面快捷方式.bat`，之后从桌面图标启动（无黑窗）。

## 托盘功能

关闭主窗口只是**隐藏到托盘**，程序继续常驻；托盘图标右键菜单：

- **托盘图标在哪**：Windows 11 默认把新应用的图标折叠在任务栏右下角的 **^（隐藏图标）** 里，
  点击 ^ 即可看到深蓝色三柱图标。想让它常驻任务栏：`设置 → 个性化 → 任务栏 → 其他系统托盘图标`
  打开本应用的开关，或直接把图标从溢出面板拖到任务栏。双击图标同样可唤出主窗口。

- **显示监控台**：唤出主窗口（左键双击图标同效）
- **立即刷新**：马上执行一次数据刷新
- **自动刷新间隔**：5 / 15 / 30 分钟或关闭（单选，默认 5 分钟，切换立即生效）
- **今日用量气泡**：弹气泡显示今日请求次数与估算花费
- **打开数据目录**：在资源管理器中打开 `agent-monitor` 目录
- **退出**：真正退出程序（托盘图标消失）

刷新行为：刷新成功不弹气泡，只静默重载页面并更新托盘悬停提示；刷新失败才弹气泡，
内容为错误输出最后 200 字。托盘悬停提示格式：`今日请求 N · 估算 ¥X`（数据读取失败时显示"数据读取失败"）。

同一时刻只允许一个监控台实例运行；重复启动会把已有实例的窗口唤到前台后自动退出。

## 成本估算口径

托盘提示中的"估算"与网页版数据说明页一致：按官方目录价（元/百万 token）
`cost = (input − cache_read) × 输入价 + cache_read × 缓存读取价 + output × 输出价`。
冻结价：GLM-5.3-Flash 0.8 / 0.23 / 2.8；GLM-5.3 8 / 2 / 28；其余模型按 0 计。
订阅套餐实际按积分配额计费，此估算不等于现金账单。

## 自检与日志

- 冒烟自检（无托盘、无单实例锁，自动化友好）：
  `python app.py --smoke`
  结果写入 `smoke_result.json`（含页面标题、请求数、今日统计），退出码 0=通过 / 1=失败。
- 运行日志：`app.log`（每行带时间戳，记录启动/托盘就绪/刷新成功失败与耗时/退出/异常）。
  双击 `.pyw` 没反应时先看日志。

## 常见问题

- **双击无反应**：查看 `app.log`；确认已运行 `安装依赖.bat`。
- **提示缺少 WebView2**：按弹窗指引安装 Microsoft Edge WebView2 Runtime 后重试。
- **端口 59321 被占用**：单实例锁失效时可能误判"已有实例"。确认没有残留的 python/pythonw 进程后再启动。
- **数据不动**：确认 ZCode 正在本机运行且 `~/.zcode/cli/db/db.sqlite` 存在；刷新失败气泡会给出原因。
- **数据库安全**：所有读取均为只读（`mode=ro` + `query_only`），不会写入 ZCode 会话库。
