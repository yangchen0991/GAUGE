# GAUGE 衡 · AI Agent 监控台 — Windows 桌面版

用系统窗口 + 托盘常驻的方式运行上级目录的 GAUGE 衡 网页版（上级目录 AI-Agent监控台.html），
无需浏览器，支持自动定时刷新与今日用量提示。

## 目录内容

| 文件 | 作用 |
|---|---|
| `app.py` | 入口层（双进程：托盘主进程 pystray + 窗口子进程 pywebview，Pipe 通信；菜单 actions、build_menu/start_tray、run() 主流程、--smoke 冒烟与 main()） |
| `monitor/` | 桌面壳支撑包（批次3a 自 app.py 拆分，依赖无环，各模块职责见下表） |
| `启动监控台.pyw` | 无控制台入口，双击即用（内部以 runpy 运行 app.py） |
| `安装依赖.bat` | 一键按仓库根 `requirements.txt` 安装运行依赖（pywebview 窗口 / pystray 托盘 / pillow 图标 / psutil 内存统计，版本锁定） |
| `构建EXE.bat` | 一键 PyInstaller 打包（等价仓库根 `python -m PyInstaller desktop/monitor.spec --noconfirm`，产物 `dist\AI-Agent监控台.exe`） |
| `创建桌面快捷方式.bat` | 在桌面生成「GAUGE 衡.lnk」（目标 pythonw.exe） |
| `README.md` | 本说明 |
| `widget.html` | 桌面贴纸页面 v2（无边框碳黑玻璃面板：积分窗口 + 近 7 天成本图） |
| `widget.json` | 贴纸配置（位置/透明度/穿透/可见性/档位 plan_tier；运行时自动生成，可手动编辑） |
| `app.log` | 运行日志（自动生成，轮转写：单文件上限 1MB，保留 3 个历史备份 app.log.1~3） |
| `monitor.ico` | 托盘/快捷方式图标（首次运行自动生成） |
| `smoke_result.json` | `--smoke` 冒烟自检结果（自动生成） |
| `monitor.spec` | PyInstaller 打包配置（hiddenimports 显式列出 monitor 全部模块） |

## monitor/ 包模块布局

| 模块 | 职责 |
|---|---|
| `appenv` | 路径/常量环境层：冻结（exe）与源码两种形态的路径解析、轮转日志（无包内依赖的最底层） |
| `singleinst` | 单实例锁（127.0.0.1:59321）：后启动侧向已运行实例发 SHOW 唤出窗口后静默退出 |
| `dialogs` | WebView2 预检与 Win32 原生弹窗（仅托盘主进程调用） |
| `traycore` | 托盘主进程共享状态与托盘图标能力：状态对象 TRAY、图标绘制、气泡通知、子进程命令发送、贴纸配置应用/持久化 |
| `refreshctl` | 数据刷新编排：源码形态子进程跑 refresh.py，exe 形态线程内 importlib 加载打包的 refresh.py；sidecar 读取与统计推送 |
| `winchild` | 窗口子进程（multiprocessing spawn 侧）：主面板与桌面贴纸两个 webview 窗口、毛玻璃/鼠标穿透/位置记忆 |
| `config` | 贴纸配置 widget.json 读写（纯函数，主进程唯一写者，tmp+os.replace 原子写，损坏自愈） |
| `stats` | 今日统计与贴纸数据包（只读直查数据库；作为 sidecar 缺失/损坏时的回退路径） |
| `pin_desktop` | 钉桌面模式：WorkerW 注入把贴纸嵌到壁纸层（图标之上、窗口之下） |

上层目录的 `refresh.py`、`AI-Agent监控台.html` 为数据与页面来源，桌面版只读复用，不做修改。
数据流：贴纸/托盘**优先消费 refresh 随成品 HTML 原子写出的 sidecar（`AI-Agent监控台.data.json`，单一统计链，与网页同源同价目）**；sidecar 缺失/损坏时回退 `monitor.stats` 只读直查数据库（`--smoke` 冒烟验证的就是直查链）。

## 环境要求

- Windows 10/11（64 位）
- Python 3.10+（本机验证：3.13.7，`python` 已加入 PATH）
- Microsoft Edge WebView2 Runtime（Win10/11 一般自带；缺失时程序会弹窗提示并可一键打开微软下载页）

## 首次使用

1. 双击 `安装依赖.bat`（等价于仓库根 `pip install -r requirements.txt`）。
2. 双击 `启动监控台.pyw`（或 `python app.py`）。
   首次运行会自动生成 `monitor.ico`；若上层目录还没有 `AI-Agent监控台.html`，会先自动跑一次数据刷新生成页面。
3. 建议运行一次 `创建桌面快捷方式.bat`，之后从桌面图标启动（无黑窗）。

## 托盘功能

关闭主窗口只是**隐藏到托盘**，程序继续常驻；托盘图标右键菜单：

- **托盘图标在哪**：Windows 11 默认把新应用的图标折叠在任务栏右下角的 **^（隐藏图标）** 里，
  点击 ^ 即可看到 GAUGE 表盘图标（碳黑底+琥珀弧，运行时生成 monitor.ico）。想让它常驻任务栏：`设置 → 个性化 → 任务栏 → 其他系统托盘图标`
  打开本应用的开关，或直接把图标从溢出面板拖到任务栏。双击图标同样可唤出主窗口。

- **显示监控台**：唤出主窗口（左键双击图标同效）
- **立即刷新**：马上执行一次数据刷新
- **自动刷新间隔**：5 / 15 / 30 分钟或关闭（单选，默认 5 分钟，切换立即生效）
- **今日用量气泡**：弹气泡显示今日请求次数与估算花费
- **官方用量页**：在默认浏览器打开 Coding Plan 官方用量页（积分明细）
- **打开数据目录**：在资源管理器中打开 `agent-monitor` 目录
- **退出**：真正退出程序（托盘图标消失）

刷新行为：刷新成功不弹气泡，只静默重载页面并更新托盘悬停提示；刷新失败才弹气泡，
内容为错误输出最后 200 字。托盘悬停提示：首行「GAUGE 衡 · AI Agent 监控台」，第二行 `今日请求 N · 估算 ¥X`
（数据读取失败时显示"数据读取失败"）。

同一时刻只允许一个监控台实例运行；重复启动会把已有实例的窗口唤到前台后自动退出。

## 桌面贴纸（v2，碳黑玻璃皮肤）

托盘菜单勾选「桌面贴纸」后，桌面会出现一块**无边框碳黑玻璃小面板**（常驻 380×460，外圆角 28；
Win11 22621+ 走 DWM Acrylic 毛玻璃，不支持的环境自动回退实底 `#101014`）。皮肤遵循
`brand/02-设计语言.md` v2.0 token（含末尾附录「桌面贴纸皮肤（特批）」）。

- **界面结构**（自上而下）：
  1. 标题行（拖动区）：GAUGE 表盘标 + 「GAUGE 衡 · AI Agent 监控台」+ 右侧今日读数 `今日 ¥X · N 次`；
  2. 状态行：同步状态灯（成功绿色呼吸 / 失败红色静止）+「已同步 HH:MM」+ ↻ 立即刷新按钮；
  3. **5h 窗口卡片**：滚动 5 小时积分用量占档位额度的百分比（琥珀大数字）、胶囊进度条、
     `已用 X / 2,000 积分`、`预计 Hh Mm 后开始释放`（临近时显示 `预计即将开始释放`，无数据显示 `预计 —`）、徽标「滚动窗口」；
  4. **本周卡片**：本自然周（周一 00:00 起）积分用量（白色大数字）、进度条、
     `自然周估算`（官方周额度重置以订阅日为准，见底栏提示）、徽标「自然周」；
  5. 近 7 天估算成本迷你柱状图（悬停显示请求/成本）+ 最近 24h 错误提示条；
  6. 底栏：口径说明（`额度=官方档位 · 消耗=本机估算`）+ 同步时间 + ⚙ 设置面板 + ↗ 官方用量页。
- **积分口径**（GAUGE 官方积分，2026-09-20 检索冻结）：按请求逐行计
  `credits = (input×输入系数 + cache_read×缓存系数 + output×输出系数) / 1_000_000`，
  系数（积分/百万 token）GLM-5.3 → (6.9, 1.7, 24)、GLM-5.3-Flash → (2.3, 0.56, 8)，未列出模型按 0 计；
  除数取值说明：官方文档字面为 /10000，与官方 V2→V3 迁移等价关系及实测数据矛盾，
  工程判定取 /1e6（2026-09-20 研究判定，非官方确认）；
  周一至周五本地 14:00–18:00 高峰 ×1.0，其余 ×0.5（官方高峰定义为 UTC+8，本产品假设本机时区=UTC+8）。
  数据与网页同源（sidecar 单一统计链，字段 `plan/window5h/thisweek`；旧 sidecar 缺键时贴纸显示 `—`）。
- **档位**：托盘「贴纸设置 → 档位」Lite（5h 2,000 / 周 10,000）/ Pro（12,000 / 60,000）/
  Max（28,000 / 140,000）单选，默认 Lite；切换后落盘 `widget.json` 的 `plan_tier` 并自动刷新生效。
- **拖动**：按住贴纸顶部标题栏拖到任意位置，位置自动记忆（存 `widget.json`）。
- **毛玻璃**：Win11 22621+ 使用 DWM Acrylic（背景透出模糊桌面）；不支持的环境自动回退实底。
- **置顶**：贴纸始终浮于普通窗口之上。
- **钉桌面模式（实验）**：托盘「贴纸设置 → 钉桌面模式」开启后，贴纸嵌入桌面壁纸层
  （图标之上、窗口之下——Rainmeter 同款机制）。与置顶互斥；explorer 重启后需重新
  开启；个别 Windows 构建不支持时会自动回退置顶并气泡提示。
- **鼠标穿透**：托盘「贴纸设置 → 鼠标穿透」开启后，点击会穿过贴纸直达下层窗口
  （适合纯展示挂机）；再次点击菜单项关闭穿透恢复交互。
- **透明度**：托盘「贴纸设置 → 透明度」60% / 75% / 90% 三档。
- **展开版（宽档）**：贴纸 header 最右侧「展开/收起」按钮，在常驻 380×460 与
  展开版 740×460（左列积分双卡 / 右列大号趋势图）之间切换；**布局状态不记忆，
  重启后回到常驻尺寸**。钉桌面模式下不支持展开（按钮自动隐藏）。
- **设置面板**：footer ⚙ 按钮打开（再点或点击面板外关闭）：透明度 60/75/90 三档、
  鼠标穿透开关、钉桌面开关，变更即时生效并落盘（透明度作用于玻璃底色 alpha）；面板底部「打开完整面板」直达主窗口。
- **隐藏/恢复**：托盘菜单「桌面贴纸」开关。
- **官方用量页**：贴纸 footer ↗ 按钮或托盘「官方用量页」菜单项，打开
  `https://bigmodel.cn/coding-plan/personal/usage` 查看官方积分明细。
- **配置文件**：`desktop\widget.json`（位置/透明度/穿透/可见性/档位），可手动编辑，主程序唯一写者。

## 成本估算口径

托盘提示中的"估算"与网页版数据说明页一致：按官方目录价（元/百万 token）
`cost = (input − cache_read) × 输入价 + cache_read × 缓存读取价 + output × 输出价`。
冻结价：GLM-5.3-Flash 0.8 / 0.23 / 2.8；GLM-5.3 8 / 2 / 28；其余模型按 0 计。
订阅套餐实际按积分配额计费，此估算不等于现金账单。

## 自检与日志

- 冒烟自检（无托盘、无单实例锁，自动化友好）：
  `python app.py --smoke`
  结果写入 `smoke_result.json`（含页面标题、请求数、今日统计），退出码 0=通过 / 1=失败。
- 运行日志：`app.log`（每行带时间戳，记录启动/托盘就绪/刷新成功失败与耗时/退出/异常；
  轮转写：单文件上限 1MB、保留 3 个历史备份）。
  双击 `.pyw` 没反应时先看日志。

## 常见问题

- **双击无反应**：查看 `app.log`；确认已运行 `安装依赖.bat`。
- **提示缺少 WebView2**：按弹窗指引安装 Microsoft Edge WebView2 Runtime 后重试。
- **端口 59321 被占用**：单实例锁失效时可能误判"已有实例"。确认没有残留的 python/pythonw 进程后再启动。
- **数据不动**：确认 ZCode 正在本机运行且 `~/.zcode/cli/db/db.sqlite` 存在；刷新失败气泡会给出原因。
- **数据库安全**：所有读取均为只读（`mode=ro` + `query_only`），不会写入 ZCode 会话库。
- **副屏混合 DPI 已知风险**：贴纸跨显示器移动后（尤其 resize 过的展开版窗口移入
  缩放比例不同的副屏），WebView2 的鼠标命中区域可能与渲染错位——表现为界面显示
  正常但点击/悬停无响应；移回主屏或重启应用可恢复。winchild 在布局切换后会执行
  窗口框架重算（SWP_FRAMECHANGED）尽力缓解，但该场景在本机（主屏 3840 宽 150% +
  副屏）实测仍可复现，属 pywebview/WebView2 层限制，根治需库升级或窗口重建机制。
