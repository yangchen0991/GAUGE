# GAUGE · 衡 — AI Agent 监控台

监控本机 ZCode 用量的桌面工具：托盘常驻 + 桌面贴纸（琥珀玻璃双布局）+ 全量统计页。

## 快速开始

1. 双击 `desktop\安装依赖.bat`（仅首次）。
2. 双击 `desktop\启动监控台.pyw` 启动（无黑窗，托盘常驻，主窗口即全量统计页）。
3. 日常操作在托盘右键菜单：显示监控台 · 立即刷新 · 自动刷新间隔 · 桌面贴纸 · 贴纸设置 · 官方用量页 · 退出。

## 桌面贴纸（v2）

- **读数**：5h 窗口 % 与本周 %（积分口径，官方档位额度做分母，托盘「贴纸设置→档位」可切 Lite/Pro/Max）、今日成本/请求、近 7 天趋势、最近错误。
- **操作**：按住 header 拖动；↻ 立即刷新；展开/收起按钮切换双布局（380×460 ↔ 740×460，展开为左额度卡右七天趋势；布局不记忆，重启回常驻）；⚙ 设置面板（透明度三档作用于玻璃底色 / 鼠标穿透 / 钉桌面 / 打开完整面板）；↗ 官方用量页（bigmodel 控制台，需登录）。
- **已知限制**：副屏混合 DPI 下展开后可能点不到贴纸（pywebview/WebView2 库层限制），主屏使用不受影响；更多见 `desktop/README.md` 常见问题。

## 目录导览

| 路径 | 作用 |
|---|---|
| `template.html` + `refresh.py` | Web 版模板与数据管线（只读 ZCode 会话库，产出成品页与统计快照） |
| `AI-Agent监控台.html` / `.data.json` | 生成的成品页与统计快照（网页/托盘/贴纸同源消费，可重新生成） |
| `刷新数据.bat` | 手动重跑一次数据刷新 |
| `desktop/` | 桌面版：`app.py` 入口、`monitor/` 支撑包、`tests/` 测试、`widget.html` 贴纸页、安装/启动/构建/快捷方式 bat |
| `docs/` | 贴纸 v2 验收截图（常驻 / 展开 / 设置面板） |
| `brand/` | GAUGE·衡 品牌资产（v2.0 设计语言与命名） |
| `build/` `dist/` | EXE 构建产物（`desktop\构建EXE.bat` 重新生成；当前已清理） |
| `.mypy_cache/` `.pytest_cache/` `__pycache__/` | 工具缓存，运行时自动再生，可随时删 |

## EXE 形态（可选）

当前 `dist/` 内的旧版 EXE 已清理。需要时双击 `desktop\构建EXE.bat` 重新构建（含贴纸 v2 全部功能），再用 `desktop\创建桌面快捷方式.bat` 生成桌面快捷方式。

## 口径与数据

- 数据源：`~/.zcode/cli/db/db.sqlite`（只读，绝不写入）。
- 成本 = 官方目录价估算，非账单；积分与百分比 = 官方系数估算，5h/周额度为官方档位积分（周口径为自然周，官方重置以订阅日为准）。技术细节见 `desktop/README.md`。
